---


# 🖥️ Sobre o Projeto

O FinTrack é uma interface moderna para gerenciamento financeiro pessoal, desenvolvida com foco em simplicidade, velocidade e boa experiência visual.

O frontend foi criado utilizando o Lovable para acelerar o desenvolvimento da interface e facilitar futuras integrações com backend próprio.
